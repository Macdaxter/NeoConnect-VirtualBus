# 0.9.0-beta.6 RC - DRAFT, NOT RELEASED

This is a release-note template only. No beta.6 public binary has been
qualified or published.

## Candidate changes

- InputSync protocol v2 with explicit epochs.
- Dedicated preflight command separated from Race Sync command `0xE4`.
- MiSTer InputSync frame-authority and frame-commit interface.
- Configuration and initial-state preflight contract.
- Matching beta.6 ESP transport build identity.

The `START MISTER` label correction and visible `DUALMODE` selection belong to
the beta.5 frontend functional line. They are carried into this candidate but
are not beta.6 architecture changes.

## Required acceptance before publication

- WAIT_COMMIT deterministic-state stall.
- 1,000/1,000 INPUT_COMMIT to FRAME_COMMIT run.
- Duplicate, stale sequence and wrong-epoch negative tests.
- Reset/rejoin pending-commit discard.
- CONFIG_MISMATCH and INITIAL_STATE_MISMATCH tests.
- Original-timing same-frame F3 duration run.
- Portable clean-system and MiSTer installer/rollback repeat.
- Complete license and corresponding-source bundle.

## Not qualified by this draft

- Fixed16/Fixed24 MAME-to-MiSTer InputSync.
- MiSTer-host direction unless separately accepted.
- ESP32/MAX485 release qualification.
- Public relay/lobby/accounts/NAT traversal.
