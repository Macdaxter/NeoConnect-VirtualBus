# 0.9.0-beta.6 RC - DRAFT, NOT RELEASED

This is a release-candidate note. No beta.6 public binary has been published
until the final archive, source and checksum gates are complete.

## Candidate changes

- MAME-to-MAME InputSync protocol v3 with explicit epochs.
- Focused MAME endpoint `MAME/neogeo.exe` SHA256
  `F05C1BAEA1BAD9826F55856F2D4DBB7D32D40C0501BC550CAB0FC0F178A8398A`.
- Dedicated preflight command separated from Race Sync command `0xE4`.
- MiSTer InputSync frame-authority and frame-commit candidate interface.
- Configuration and initial-state preflight contract.
- Matching beta.6 ESP transport build identity.
- Coin/System input authority for synchronized InputSync sessions.
- Fail-closed handling on sync loss.

The `START MISTER` label correction and visible `DUALMODE` selection belong to
the beta.5 frontend functional line. They are carried into this candidate but
are not beta.6 architecture changes.

## Required acceptance before publication

- Regenerated public user archive from the final package directory.
- SHA256 sums for every shipped central binary.
- Corresponding source and third-party license bundle.
- Portable clean-system smoke outside the development tree.
- MiSTer installer/rollback repeat if MiSTer files are included as public
  supported artifacts.

## Not qualified by this draft

- Fixed16/Fixed24 MAME-to-MiSTer InputSync.
- MiSTer InputSync v3 physical parity unless explicitly accepted in the final
  release.
- MiSTer-host direction unless separately accepted.
- ESP32/MAX485 release qualification.
- Public relay/lobby/accounts/NAT traversal.
