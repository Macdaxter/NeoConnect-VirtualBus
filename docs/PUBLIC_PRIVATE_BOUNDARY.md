# Public and Internal Boundary

## Public repository

- Project overview and publication-safe assets cleared for publication.
- Beta scope, installation and protocol overview.
- Project charter, changelog and contribution guidance.
- Release notes, checksums and release verification tooling.
- License texts, notices and corresponding-source references.

## GitHub Release assets

- One qualified `User_USB_Portable` ZIP.
- One corresponding-source ZIP required by redistributed licenses.
- One SHA256 file covering the immutable assets.

## Internal archive

- Developer Reference package.
- Complete Laboratory and diagnostic logs.
- Historical LKGs and intermediate binaries.
- Research snapshots and `_review_needed` material.
- Private configuration, credentials and machine-specific paths.

Public issue attachments are reviewed separately; an internal diagnostic bundle
is never uploaded wholesale.
