# Third-Party Notices

VirtualBus release packages aggregate components from multiple projects. The
final release must include the full license texts and notices belonging to the
exact packaged versions.

| Component | Project | Release obligation status |
| --- | --- | --- |
| MAME Neo Geo executable | MAMEdev | GPL-2.0 license known; public corresponding-source bundle required. |
| NeoGeo MiSTer core | MiSTer NeoGeo/Furrtek contributors | GPL-2.0 license known; exact modified core source required. |
| MiSTer HPS executable | MiSTer project | Exact upstream license and modified source must be verified before publication. |
| esptool | Espressif | License is retained internally; public package/source linkage must be verified. |
| Portable frontend runtime | Python, Tcl/Tk, PyInstaller and modules | Exact bundled notices must be generated from the final build. |
| Transfer tools | PuTTY project | Exact binaries and license text must be verified in the final package. |

This table is intentionally a gate. A component is not approved for public
distribution merely because its binary works.
